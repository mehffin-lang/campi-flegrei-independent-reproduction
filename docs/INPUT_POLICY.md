# Input policy for the resumed run

The latest instruction expressly permits the external INGV routine catalog for Figures 1A, 1C and S5, and specifically documented external calibration inputs. These panels use routine records, not independently detected events. INGV duration magnitudes may regularize independently measured relative-amplitude equations, as required by supplementary S6. They do not seed association, choose waveform dates, or fill missing magnitudes. The independent association script never opens the routine catalog.

Permitted inputs used: original INGV IV/2I waveforms and responses; released PhaseNet weights/configuration and station coordinates; generic SeisBench and GaMMA software; the original Del Gaudio et al. (2010) numerical leveling table; and the released fixed external-background 3D model as a separately identified sensitivity input. The paper attributes its fixed background to Battaglia et al. (2008); the release README identifies this file as the TomoDD input. Its byte identity against an original 2008 release has not been established. The current association alternative instead uses the numerical layer table in Tramelli et al. (2021), Table 1. It is not asserted identical to Calo--Tramelli (2018). Independently calculated regional 3D averages initialize the VELEST pilot; no Tan-fitted model is used.

Excluded from analysis inputs: Tan's fitted 1D model, station corrections, picks, associations, catalog, focal solutions, study scripts and plot data. The supplied ZIPs passed directory/CRC checks. After independent results existed, Data S1 was read solely for final temporal-match and horizontal-difference assessment in `scripts/final_comparison.py`. Its outputs are isolated in `data/comparison/`; no upstream analysis reads that directory. Data S3 was read only to count rows/nonempty fields in a final documentation audit: 74 rows and 58 gCAP entries, despite its caption's 55. No supplied numerical solution entered inference or tuning. The interactive HTML was not executed.

The local waveform archive was inspected through HTTP ranges: 319,890 members, including original miniSEED observations. One observation was read for readability only. These traces are conditioned on author detections (-5 to +55 seconds), and cannot establish independent continuous detection completeness. They were not used to generate events or figures. This is an event-selection limitation, not a claim that the observations are forbidden in every downstream context.

The original leveling table was retrieved from the publisher and parsed with antiword. The official De Martino GNSS ZIP was listed and CRC-tested; only RITE observations and its format README are used, without executing anything. A constant datum offset is estimated from overlapping leveling observations, not from Tan results. A later copy and an interpolated displacement compilation were inspected for provenance only; neither supplies plotted values. Dates use the fifteenth of the stated month as an explicit display convention. Uncertain months and original observation/estimate descriptions are retained.

Generic VELEST, HypoDD and gCAP are method software, not Tan's study scripts. VELEST was built with platform-only repairs and is not presented as a completed scientific inversion. The science.adw9038 ZIPs were never extracted or executed. No published figure was digitized.

Current GNSS observations and their format notes are from Zenodo 17132077 and 22259337. These independent INGV geodetic observation releases, including 2025, are permitted original observations, not Tan-derived results. No JPG or graph is an input. Natural Earth coastlines are an attributed external basemap. The extra source bundle contains only classified permitted context/metadata/written-method files. Generic TomoDD training source was classified and built; example data/results and plotting scripts were excluded.

The current final comparison in `data/comparison_continuation/` is produced only after independent VELEST outputs and plots exist. Data S1 provides final comparison reference times/locations; it is not read by collection, picking, association, calibration, location or plotting. The comparison cannot alter any upstream output or parameter.
