# Calibration and relocation follow-up

This is an executed exploratory continuation, not an accepted regional calibration or a complete reproduction. Start from the existing project checkout and its Python environment. The main paper and supplement remain `tanmodel.pdf` and `tanmodelsupp.pdf`. Their readable methods and captions were checked before new analysis; the archive listings contain author-derived catalogs, phases, mechanisms and an interactive plot, not initial observations. None enters this workflow.

## Executed processing and acceptance

`scripts/calibration_chain.py` selects 130 causally consistent candidates with >6 picks and initial gap <180°. This is an explicit unreviewed selection assumption; the supplement gives a count of 373 high-quality calibration events, not a reproducible numerical selection rule. The alternative-profile chain runs two calibration rounds in both real precisions, then five fixed-model/correction catalog passes with the written 0.4 s and 0.3 s residual rejection. Events with fewer than four remaining observations cannot enter the next numerical solve, an explicit departure. The final ≥6-pick, RMS ≤0.25 s, gap ≤300° filters leave 238 exploratory locations. All data and model units are km, seconds and km/s; station elevation is converted from meters, positive upward, to depth below sea level. Absolute own-pick times are preserved across rounded origin-time serialization.

`scripts/calibration_validation.py` continues iterations, recomputes the generic solver's reported weighted-residual statistic and checks sampled station epochs. Models agree at printed precision between 32 and 64 bits, but locations do not converge under further iterations. The held-out unweighted phase RMS worsens despite a lower aggregate reported event statistic. `scripts/calibration_selection_check.py` executes one declared sensitivity trial (≥4 P, ≥2 S, no initial depth-bound hit): its continued fit and held-out training branch produce Vp ≤ Vs and are rejected. These failures are preserved, not treated as valid fitted models or filled with author results.

`scripts/relocation_followup.py` preserves original observed arrival times and computes neighbor waveform delays from the filtered exploratory locations. Windows, response corrections, coherence weighting and their assumptions are retained from `differential_times.py`. It runs **HypoDD**, not TomoDD. The two LSQR rounds leave 127 and 126 exploratory estimates. Four quadrants about 14.14°E, 40.82°N are declared alternatives to the paper's unspecified numerical regional masks. SVD uses the largest connected component only after recorded small-component failures; NW/SW/SE return 40/16/22 estimates, and NE diverges. Generic SVD errors are 1.96 standard errors, conditional on these observations and model. LSQR error columns are not interpreted as uncertainties. Zero magnitude/initial-error fields are required, unused HypoDD serialization fields, not measured values; they never supply magnitude plots. Generic HypoDD clamps two below-sea-level station elevations to zero (recorded in solver logs), another departure relevant to accurate depths.

The HypoDD `matmult2.f` output dummy vector was incorrectly declared with the number of columns rather than output rows. The build changes `c(n)` to `c(m)` and retains bounds checking. `tests/check_hypodd_matrix.py` is an isolated **synthetic arithmetic fixture**. It does not enter observations, catalogs, magnitude equations or empirical plots. Rejected trials and conditional diagnostics remain distinct from accepted scientific results. The NE failure has a zero process exit code but empty numerical output; the workflow records it as failed.

## Rebuild and verification

All commands run at the repository root. The existing full-subset procedure in `CONTINUATION.md` remains available; this follow-up builds on its frozen independent outputs rather than rerunning the earlier full project unnecessarily.

```bash
# Restore recorded observations/method inputs; hash mismatch stops restoration.
.venv/bin/python scripts/restore_inputs.py --calibration-followup

# Rebuild this follow-up, using the hash-verified expanded association checkpoint.
.venv/bin/python scripts/rebuild_calibration_followup.py

# Optional: also rerun expanded association and any uncached per-file inference.
.venv/bin/python scripts/rebuild_calibration_followup.py --fresh-association
```

The default rebuild compiles both VELEST precisions and generic HypoDD; reruns all calibration, waveform differential-time, HypoDD and validation trials; audits response coverage and the frozen request ledger; regenerates plots from saved numerical outputs; compiles both PDFs; and checks the explicit data-to-plot chains. It does not initiate new full-period downloads. Compatible older waveform-window caches are verified before use; no author-produced phase/window outputs are used. Expanded inference settings and the original model identity remain frozen. To recompute every expanded inference cache, use the existing per-file cache controls documented in `CONTINUATION.md`; `--fresh-association` by itself does not mean all neural inference is recomputed.

Actual commands, exit codes, durations and the outcome are in `data/calibration_followup/rebuild_status.json`. Procedure success means the recorded experiments and documents were built, **not** that scientific validation passed. `verification.json` records scope and hashes; it cannot prove that no unexamined or hidden historical inputs existed. `run_records.zip` contains this implementation's own controls, serialized observations, models and logs, including rejected runs, with a member hash inventory. It contains no generic solver source/binary or author-derived result table. Project-specific caches and intermediate files stay under `inputs/`, `build/` and `tmp/`; those directories remain ignored. Normal dependency caches may use `/home/mehffin/.cache/pip`.

## Figures and provenance

Figure 1A and S5 retain their saved **external routine-catalog** selections. `scripts/routine_plot_style.py`, called by `plot_continuation.py`, changes presentation only: black background, white axes, a red-to-blue depth palette, exponential magnitude-to-area mapping, legends, ticks and the map/section layout. The paper does not specify the exact area law, so `0.7 + 3 * 10**(Md-2)` points squared is explicitly assumed. The additive display offset keeps small events visible while retaining a strictly increasing size mapping. Missing magnitudes use a distinct cross, not an inferred magnitude. Color ranges extend to 0–8 km (1A) and 0–6 km (S5), covering their observed maxima of 7.2 and 5.4 km. These extensions and off-view event counts are disclosed. Original elevation relief and geographic annotations were not reconstructed or copied from pixels. The saved S5 depths match the raw public HTML: all 12,503 are on a 0.1 km grid (51 distinct depths). The resulting bands are retained, not jittered or smoothed; precision is not an accuracy estimate. No Figure 3 or 4A–B counterpart is generated without accepted independent inputs. `routine_plot_style.json` records numerical-input hashes and plotting choices.

The convergence and conditional SVD figures are explicitly labeled **reproduction diagnostics**, appear only after the reproduced supplement, and are not counted as S6/S7 counterparts. Their input tables are `convergence_plot.csv` and `svd_diagnostic_plot.csv`. Published figure crops remain solely in `report/comparison.pdf`, labeled “Published reference”; they are never read by empirical plotting code.

No panel status is promoted: 12 partial panel/views, 51 unreproduced, zero fully reproduced. The complete 63-view inventory is `docs/panel_record.json`.
